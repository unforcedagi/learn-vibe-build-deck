# Learn, Vibe, Build — lessons index

ATLS 4519 · CU Boulder · Fall 2026 · Aaron Neyer. Each lesson is a separate markdown file; open only what you need.

- [Week 1 — Orientation: Learn, Vibe, Build](https://cu.learnvibe.build/lessons/week-1/lesson.md): What this course is, the three C's (cognition, communication, creativity), the weekly rhythm, and the first shared practice.
- [Week 2 — Build night](https://cu.learnvibe.build/lessons/week-2/lesson.md): Tool tour, then building together in class: pick one tool, set it up, prove it works.
- [Week 3 — Everyone demos, then the tools](https://cu.learnvibe.build/lessons/week-3/lesson.md): Everyone shows what they built; then the AI tool landscape and how to choose.
- [Week 6: Context That Sticks, and Getting Online](https://cu.learnvibe.build/lessons/week-6/lesson.md): Your AI only knows what it can see. Give it your project's context in a markdown file so it sticks, and put your project online with a link anyone can open.
