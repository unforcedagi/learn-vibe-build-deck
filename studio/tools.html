Tools

What the class is using, what it costs, and what it's actually good at. This page grows from real use: when a project lands on the wall, it names its tools, and what we learn collects here.

Start here — three good ones

All three are free to a student right now, and each one can build a whole project from a description. Pick one and get it running tonight; try the other two later.

Terminal agent

1. OpenCode + GitHub Copilot

OpenCode is an open-source agent that runs in your terminal. It signs in with a GitHub Copilot account, and Copilot is free for students.

  1. Get GitHub Copilot: the free tier at github.com/features/copilot, or the free Student plan through education.github.com — verify with your CU email.
  2. Install OpenCode from opencode.ai: curl -fsSL https://opencode.ai/install | bash
  3. Run opencode, type /connect, pick GitHub Copilot, and finish the device login at github.com/login/device.
  4. Open a folder and describe what you want built.

Local models: install Ollama (ollama.com), pull qwen2.5-coder:7b, and OpenCode can use it with no account at all.

Prefer an editor over a terminal? Zed (zed.dev) is free and runs external agents like Codex CLI with your own keys; it's the editor-shaped alternative to OpenCode.

Copilot Free: 2,000 completions + 50 chats/mo · Copilot Student (free with GitHub Education): unlimited completions, 200 credits/mo, Copilot CLI · OpenCode and Ollama: free

Not yet used in class

Agentic code editor

2. Antigravity

Google's agentic editor — agents that plan, write, and test code across the editor, terminal, and browser.

  1. Go to antigravity.google and sign in with a Google account. The free Individual plan takes no card.
  2. Download the app for your machine.
  3. Pick a model: Gemini 3.8 Flash, Claude Sonnet or Opus 4.6, or gpt-oss-120b.
  4. Optional terminal CLI: curl -fsSL https://antigravity.google/cli/install.sh | bash gives you agy.

The free plan has weekly rate limits — the number isn't published, so you find it by hitting it.

Free Individual plan, no card · weekly limits (not published) · US students can add 12 months of Google AI Pro, which needs a payment method and auto-renews

Not yet used in class

Coding agent

3. Codex

OpenAI's coding agent, in a terminal or as an app. Describe the thing, it builds it.

  1. Get a personal ChatGPT account at chatgpt.com. Free works. Your CU ChatGPT Edu login does not include Codex.
  2. Install: curl -fsSL https://chatgpt.com/codex/install.sh | sh, or download the Codex app.
  3. Sign in with that personal ChatGPT account.
  4. Open a folder and go.

Free limits: not published · Plus $20/mo raises them · ChatGPT Edu is free at CU (short required training via OIT) but does not include Codex

Used in class: week 1 demo

Also good

Everything else worth knowing about, free or with a real free tier. Any of these counts for a weekly cycle.

Chat + coding agent

Claude + Claude Code

Strong at writing, reasoning, and agentic coding. Claude chat has a free tier. Claude Code runs in a terminal and builds whole projects, but needs a paid plan.

Claude chat: free tier · Claude Code: paid only, Pro $20/mo and up · free Claude Sonnet & Opus 4.6 also inside Google Antigravity

Used in class: the class site is built by a Claude agent

AI code editor

Cursor

A code editor with AI built in — good middle ground when you want to see and touch the code while AI writes most of it.

Free tier: yes, Hobby (no card, limited Agent requests on the Auto model) · No free student year is offered now; Cursor says to look for promotions at on-campus events this fall

Not yet used in class

AI code editor

Zed

A fast editor that runs external agents — Codex CLI and others — with your own keys. The editor-shaped alternative to OpenCode.

Free forever (zed.dev) · you bring the agent and its account

Not yet used in class

Chat + multimodal

Gemini

Google's models — strong multimodal (images, video, long documents). Gemini 3.8 Flash is the current free model. The old Gemini CLI was discontinued and replaced by the Antigravity CLI.

Free tier: yes · Antigravity CLI: free, curl -fsSL https://antigravity.google/cli/install.sh | bash · US college students: free year of Google AI Pro, redeem by Dec 31, 2026 (needs a payment method; auto-renews)

Not yet used in class

Chat companion

Grok

xAI's Grok — fast chat and search, good for questions and riffing while you build. On grok.com and X. The coding CLI, Grok Build, needs a paid plan — no free coding path.

Chat: free tier, paid from $10/mo · Grok Build: requires SuperGrok or X Premium+

Not yet used in class

Run models on your own laptop. Free, private, works offline. qwen2.5-coder (7B or 14B) is the laptop-sized pick.

Coding assistant

GitHub Copilot

GitHub's assistant, built into editors and the terminal. It's the login for OpenCode above, and it also works on its own in VS Code.

Copilot Free: 2,000 completions + 50 chats/mo · Copilot Student (free with GitHub Education): unlimited completions, 200 credits/mo, Copilot CLI

Not yet used in class

Agentic IDE

Amazon Kiro

Amazon's agentic IDE. Social login, no card, and it runs open-weight models alongside Claude.

Free: 50 credits/mo (kiro.dev) · open-weight models + Claude Sonnet 4.5

Not yet used in class

Personal agent

Muse (Meta)

Meta's personal agent app: email, plans, forms, research. Not built as a coding tool, but worth a try on the free tier. The coding version, Muse Code, is a terminal agent that meters every token.

Muse app: free tier, paid $20/mo and $100/mo (ai.meta.com/muse) · Muse Code: free to install, no free usage, about $1.25 in / $4.25 out per million tokens, cheaper if you let Meta train on your code

Not yet used in class

Browser app builders

Bolt, Lovable, Base44

Describe an app in a browser tab and get a working build, no local setup. Good for one small app at a time.

Bolt.new: 300K tokens/day free · Lovable: 5 credits/day free (30/mo cap) · Base44: 25 messages/mo free (5/day)

Not yet used in class

Not free this term

Good tools with no free path right now. Use them only if you already pay for them — nothing in this class requires it.

  • Claude Code — needs Claude Pro, $20/mo and up.
  • Cursor Pro — the free student year is no longer offered.
  • Grok Build — needs SuperGrok or X Premium+.
  • Kimi Code — paid plan only.
  • Qwen Code — the free tier ended April 2026.
