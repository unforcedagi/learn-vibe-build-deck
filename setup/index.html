Setup

Tonight you set up, then you build. Work down this page in order — accounts, one tool, one proof.

Step 1 — Accounts

All free to start. Make them now; you'll want them all semester.

  • Google account — then claim the student offer: a free year of Google AI Pro for US college students, claim by Dec 31, 2026 (needs a payment method; set a reminder to cancel before it renews).
  • Claude — sign up at claude.ai. The free tier is enough for chat; Claude Code needs a paid plan (below).
  • ChatGPT — chatgpt.com. ChatGPT Edu is free for CU Boulder students — a short required AI training unlocks it.
  • GitHub — github.com/signup. Where your work will live and how you'll ship it to the web.

Step 2 — Pick ONE tool and install it

They're all good. Choose one, go deep. You can switch later.

Terminal agent

Claude Code

Install (Mac/Linux): curl -fsSL https://claude.ai/install.sh | bash · Windows PowerShell: irm https://claude.ai/install.ps1 | iex. Then run claude in a project folder. Official docs.

Needs Claude Pro ($20/mo) or an API key.

Terminal agent + ChatGPT

Codex

Install the CLI: npm install -g @openai/codex, then run codex and sign in with ChatGPT. Or use it inside ChatGPT. Official docs.

Free taste on any ChatGPT account; real sessions need Plus ($20/mo). CU's Edu accounts can't sign into Codex yet — CU says that's coming later this year.

Agentic editor

Antigravity

Download from antigravity.google/download, install, sign in with your Google account. Have Chrome installed — its agents use it for browser testing.

Free (weekly quota); the student AI Pro year raises its limits.

AI code editor

Cursor

Download from cursor.com/download, install, sign in. Open a folder and press the AI panel shortcut it shows you.

Free hobby tier; Pro $20/mo. Student free-year closed June 2026.

Chat companion

Grok

No install — use grok.com, the app, or Grok on X.

Free tier; SuperGrok $30/mo if you want more.

Step 3 — Prove it

Ask your tool to make you a one-page website about something you love. Open it in a browser. That's it — you're building.

More on what each tool costs and what it's good at: the tools page. When your tiny thing works, claim your tile on the studio wall.
