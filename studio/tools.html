Tools

What the class is using, what it costs, and what it's actually good at. This page grows from real use: when a project lands on the wall, it names its tools, and what we learn collects here.

Chat + coding agent

ChatGPT + Codex

The shared class floor. ChatGPT Edu is free with your CU login. Codex is the coding-agent side — build apps by describing them.

ChatGPT Edu: free at CU · Codex: $100 student credits, we claim them together in week 2

Used in class: week 1 demo

Chat + coding agent

Claude + Claude Code

Strong at writing, reasoning, and agentic coding. The free tier is enough for real vibecoding. Claude Code runs in a terminal and builds whole projects.

Free tier: yes, enough for real vibecoding · Paid from $20/mo · students can apply for ~$50 in API credits (Anthropic Student Builders)

Used in class: the class site is built by a Claude agent

AI code editor

Cursor

A code editor with AI built in — good middle ground when you want to see and touch the code while AI writes most of it.

Free tier: yes · The student free-year closed to new sign-ups June 2026; grad students & researchers can request credits via Cursor's form

Not yet used in class

Chat + multimodal

Gemini

Google's models — strong multimodal (images, video, long documents) and generous free access.

Free tier: yes · US college students: free year of Google AI Pro, claim by Dec 31, 2026 (needs a payment method; cancel before it renews)

Not yet used in class
