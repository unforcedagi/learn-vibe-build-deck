Markdown is just a text file

  • A .md file is plain text, with headings and lists.
  • You can read it. Your AI can read it.
  • A lesson or project context can live in that file.
Week 6 · Context4 / 13

Context that sticks

  • Claude Code loads CLAUDE.md at session start.

  • In a chat app: paste the file or add it to a Project.
Week 6 · Context5 / 13

One small example

# Hill Plant Swap
A one-page website for a free plant swap near CU.
For first-year students who are nervous about going.
Keep it plain HTML and CSS. No JavaScript.
Use docs/event-facts.md. Never make up dates.

Plain words. Nothing fancy.

Week 6 · Context6 / 13

A link someone else can open

  • file:// and localhost links only work on your computer.
  • A public HTTPS link works on someone else’s phone.
  • Commit → push → deploy are three different steps.
Week 6 · Getting online7 / 13

The short path online

  • GitHub Desktop: create repo → commit → publish.
  • GitHub: Settings → Pages → main / root → Save.
  • Open the published link on another phone.
